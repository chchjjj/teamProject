# 🍰 디저트 연구소 
> 소비자도 판매자도 편리하게 이용하는 디저트 중개 플랫폼!
## 💡 프로젝트 소개
디저트 연구소는 풍부한 수제 디저트 중심의 중개 플랫폼으로,
의미있는 커스텀 디저트를 구매하고 싶지만 **시간적 제약이 있거나 구매 과정의 피로도를 느끼는 소비자들을 위한** 사이트입니다.


- 판매자별 다양한 옵션 제공을 통해 바로 견적 확인 가능
- 소비자 주변 업체 조회 및 알레르기 원재료 필터 검색 기능을 통한 편리한 서비스를 제공
- 단순한 후식·간식이 아닌, 감성과 취향을 담은 수제 디저트 쇼핑

## 📌 주요 기능
### **✔ 사용자 기능**
 - 회원가입 및 로그인 (문자 통합인증)
 - 쇼핑몰 기능 : 카테고리, 검색, 장바구니, 위시리스트, 결제
 - 구매자 마이페이지 : 주문 목록, 채팅 이력, 내가 쓴 게시글, 정보 수정
 - 내 주변 디저트 찾기 : 카카오맵 기반 사용자 주소 주변 입점 업체 검색
 - 알레르기 프리 : 특정 알레르기 유발 원재료를 체크하여 해당 재료가 미포함된 상품 검색
   
   
### **✔ 판매자 기능**
 - 입점 신청
 - 새상품 등록, 기존 상품 수정, 가게정보 수정
 - 판매내역 조회, 캘린더 관리 및 채팅을 통한 기타 금액 변경, 게시글 관리

   
### **✔ 관리자 기능**
 - 전체 사용자 관리, 입점 신청자 관리 (승인 및 거절)
 - 배너 광고 및 멤버쉽 관리
 - 매출 조회
 - 게시글 관리
