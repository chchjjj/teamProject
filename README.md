## 💡 프로젝트 소개
디저트 연구소는 풍부한 수제 디저트 중심의 중개 플랫폼으로,
의미있는 커스텀 디저트를 구매하고 싶지만 **시간적 제약이 있거나 구매 과정의 피로도를 느끼는 소비자와 판매자를 위한** 사이트입니다.


- 판매자별 다양한 옵션 제공을 통해 바로 견적 확인 가능
- 소비자 주변 업체 조회 및 알레르기 원재료 필터 검색 기능을 통한 편리한 서비스를 제공
- 단순한 후식·간식이 아닌, 감성과 취향을 담은 수제 디저트 쇼핑

## 📌 주요 기능
### **✔ 사용자 기능**
 - 회원가입 및 로그인 (문자 통합인증)
 - 쇼핑몰 기능 : 카테고리, 검색, 장바구니, 위시리스트, 결제, 픽업/배송 선택 및 채팅
 - 구매자 마이페이지 : 주문 목록, 채팅 이력, 내가 쓴 게시글, 정보 수정
 - 내 주변 디저트 찾기 : 카카오맵 기반 사용자 주소 주변 입점 업체 검색
 - 알레르기 프리 : 특정 알레르기 유발 원재료를 체크하여 해당 재료가 미포함된 상품 검색
   
   
### **✔ 판매자 기능**
 - 입점 신청, 멤버쉽 신청
 - 새상품 등록, 기존 상품 수정, 가게정보 수정, 캘린더 관리를 통한 주문량 조절
 - 판매내역 조회, 캘린더 관리 및 채팅을 통한 기타 금액 변경, 게시글 관리

   
### **✔ 관리자 기능**
 - 전체 사용자 관리, 입점 신청자 관리 (승인 및 거절)
 - 배너 광고 및 멤버쉽 관리
 - 매출 조회
 - 게시글 관리

## ✨ 역할 분담
### 😀 최현지
- **주요 페이지** : 메인페이지, 내주변 디저트찾기, QnA, 알레르기 프리, 채팅
- **구현 기능** : 헤더 메뉴와의 기능 연결, 검색, 메인페이지 멤버쉽 홍보, 배너광고 생성 및 수익 반영, 카카오맵 API, 실시간 채팅(웹소켓), 관리자페이지 보완, 팀장(회의, 깃허브, 구글 드라이브 관리 등)
### 😉 김예슬
- **주요 페이지** : 상품상세페이지, 장바구니, 위시리스트, 판매자 프로필
- **구현 기능** : 상세옵션 및 장바구니 수량에 따른 실시간 금액 변동, 주문서 생성, 구매자-판매자 캘린더 연결(달력 API), 판매자별 페이지, 헤더/푸터 제작, 로그인/메인/상세페이지 등의 전반적 CSS, 메인페이지 메뉴화면 보완, 발표자료 생성
### 😄 조원정
- **주요 페이지** : 로그인, 회원가입, id찾기, 비번 찾기, 결제 페이지, 배송지 선택 및 추가
- **구현 기능** : 아이디/비밀번호 찾기, 회원가입 유효성 검사, 비밀번호 해시, coolsms 문자인증 API, 포트원 결제 API, 주소 API
### 😎 엄재준
- **주요 페이지** : 입점신청, 판매자 마이페이지 속 파생 페이지 전체
- **구현 기능** : 주소 API, Apex chart, 달력 API, 상품 등록(사진첨부), 상품 개별 수정, 판매내역 조회, 멤버쉽 가입 및 탈퇴, 주문 캘린더 및 게시글 관리(판매자 개별 리뷰, QnA)
### 🧐 이미령

- **구현 기능** : Apex chart, 전체 사용자 및 게시글 CRUD, 멤버쉽관리, 수익 구조에 따른 수수료 정산 기능 / 구매목록(옵션 이력 불러오기), 결제 상태에 따른 리뷰 작성 기능
