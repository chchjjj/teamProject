# 🍰 디저트 연구소 
> 소비자도 판매자도 편리하게 이용하는 디저트 중개 플랫폼!
## 💡 프로젝트 소개
디저트 연구소는 의미있는 커스텀 케이크를 구매하고 싶지만, **시간적 제약이 있거나 구매 과정의 피로도를 느끼는 소비자들을 위한** 디저트 중심 중개 플랫폼입니다.


- 판매자별 다양한 옵션 제공을 통해 바로 견적 확인 가능
- 소비자 주변 업체 조회 및 알레르기 원재료 필터 검색 기능을 통한 편리한 서비스를 제공
- 단순한 후식·간식이 아닌, 감성과 취향을 담은 수제 디저트 쇼핑
